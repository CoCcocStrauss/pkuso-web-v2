# 颜色配置优化计划

## 任务目标
优化网页的颜色配置，使亮色调以黑白为主，暗色调以黑深灰灰为主，同时确保舒适度和眼睛保护。

## 任务分解

### [x] 任务 1: 更新全局颜色配置
- **优先级**: P0
- **依赖**: 无
- **描述**:
  - 修改globals.css中的body颜色配置
  - 调整亮色调和暗色调的基础颜色
  - 确保符合用户要求的黑白为主色调
- **成功标准**:
  - 亮色调以黑白为主，暗色调以黑深灰灰为主
  - 页面整体色调舒适，不刺眼
- **测试要求**:
  - `programmatic` TR-1.1: 页面能正常加载，无颜色类错误
  - `human-judgement` TR-1.2: 亮色调和暗色调切换时视觉舒适

### [x] 任务 2: 更新提示色配置
- **优先级**: P1
- **依赖**: 任务 1
- **描述**:
  - 为亮色调配置高亮度的主色作为提示色
  - 为暗色调配置暗色调的主色作为提示色
  - 确保提示色在两种模式下都清晰可见
- **成功标准**:
  - 提示色在亮暗模式下都能有效吸引注意力
  - 提示色与背景色对比合理，不刺眼
- **测试要求**:
  - `programmatic` TR-2.1: 提示色类能正常应用
  - `human-judgement` TR-2.2: 提示色在两种模式下都清晰可见

### [x] 任务 3: 更新react-datepicker样式
- **优先级**: P2
- **依赖**: 任务 1, 任务 2
- **描述**:
  - 更新react-datepicker-orchestra的样式，使其符合新的颜色配置
  - 确保日期选择器在亮暗模式下都美观舒适
- **成功标准**:
  - 日期选择器的颜色与整体页面风格一致
  - 日期选择器在亮暗模式下都清晰易用
- **测试要求**:
  - `programmatic` TR-3.1: 日期选择器能正常显示和交互
  - `human-judgement` TR-3.2: 日期选择器的颜色配置符合要求

## 实现方案
1. 在globals.css中使用Tailwind v4的@theme指令定义颜色变量
2. 为亮色调和暗色调分别设置合适的颜色方案
3. 确保颜色对比度符合WCAG标准，提高可读性
4. 测试亮暗模式切换时的视觉效果

## 注意事项
- 不要修改与色调、外观无关的代码
- 考虑眼睛保护，避免使用过于刺眼的颜色
- 确保颜色配置在两种模式下都舒适自然
- 保持代码简洁，只修改必要的颜色相关配置
